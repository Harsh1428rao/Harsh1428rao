## Featured Projects

### [webhookd](https://github.com/Harsh1428rao/webhookd) · Webhook Delivery System
`Go` `PostgreSQL` `Docker` `GitHub Actions`

A reliable event-delivery backend, modeled on the infrastructure behind platforms like Stripe and GitHub webhooks.

- Concurrent delivery workers built on goroutines
- Retries with exponential backoff (1s → 2s → 4s → 8s → 16s)
- HMAC-SHA256 payload signing and JWT authentication
- PostgreSQL audit trail of every delivery attempt
- 10 REST endpoints, containerized with automated CI/CD
